01 / RAG systemsLive application

Campus Desk

Ask questions about a school handbook and inspect the passages behind each answer.

FastAPI · Next.js · FastEmbed · SQLite FTS5 · RapidOCR

Try Campus Desk
View project details

Problem

School information is spread across long handbooks and notices. This application brings document search and cited answers into one interface.

Retrieval & context

PDF and Word extraction, OCR for scans, and heading-aware overlapping chunks retain page or paragraph references. BM25 and semantic rankings are combined with reciprocal rank fusion; follow-up questions can be rewritten before retrieval.

Backend & delivery

A Python API streams ingestion progress and answers. Workspace storage, frontend/backend contract checks, bounded provider retries and a source-search fallback make failures visible. Retrieval, prompt construction and generation each have an inspection view.

Scope

A deployed demonstration. Workspace separation is not authenticated access, and a valid citation number alone does not establish answer correctness.

02 / RAG systemsLive application

Study Companion

Explore lecture notes, compare chunking strategies, and practise with source-linked questions.

FastAPI · Next.js · Hybrid retrieval · Parent-section context

Try Study Companion
View project details

Problem

A useful study answer needs enough context to explain a topic while retaining the original notes and their caveats.

Retrieval & context

The same notes are indexed as section-aware chunks and fixed-length windows. A comparison view runs the same question through both. Short matches can expand to their parent section within a word budget.

Backend & delivery

Shared extraction, embedding and retrieval modules avoid duplicating the Campus Desk pipeline. Streamed explanations expose supporting sections; quizzes and flashcards check their quoted evidence against the notes.

Scope

A deployed demonstration. Chunking comparisons describe retrieved context; they do not establish that one strategy is universally better. Practice content still needs review.

03 / RAG systemsDevelopment lab

RAG Build Lab

A shared Python retrieval core with ten separately runnable workflows.

Python · SQLite FTS5 · Streamlit · Optional semantic search

View project details

Architecture

Separate demo configurations share indexing, retrieval, provider adapters and workflow code. Campus Desk and Study Companion extend the core with document-upload APIs and web interfaces.

Engineering focus

The lab explores source metadata, keyword and semantic retrieval, rank fusion, optional reranking, document comparison and bounded search workflows. Small evaluation fixtures and automated checks exercise specific behaviours.

Scope

This is a development repository, not ten production services. Synthetic fixture checks are not real-world accuracy benchmarks. Source is currently private; the two public applications above provide live entry points.
